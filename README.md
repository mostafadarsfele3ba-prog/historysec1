# ألعاب التاريخ التفاعلية – المؤرخ سعيد إسماعيل

مشروع ألعاب تعليمية تفاعلية لمادة التاريخ (مصر الحضارة: حضارة مصر والعالم القديم) – الصف الأول الثانوي – الفصل الدراسي الأول.

- **9 درسًا** في وحدتين (الأولى والثانية)، ولكل درس صفحة مستقلة بها 5 ألعاب (100 سؤال):
  اختيار من متعدد – الفقاعات المتساقطة – التنشين والاصطياد – صح أم خطأ – تحدي العباقرة.
- من الصفحة الرئيسية يمكن **نسخ رابط أي درس** أو مشاركته على واتساب، أو نسخ روابط كل الدروس مرة واحدة.
- إرسال النتيجة للمعلم عبر واتساب: 01092010797

## هيكل الملفات
```
index.html              الصفحة الرئيسية (كل الوحدات والدروس + نسخ الروابط)
assets/logo.jpg         صورة المعلم
lessons/uX-lY.html      صفحة كل درس (X = رقم الوحدة، Y = رقم الدرس)
```

## النشر على GitHub Pages
1. ارفع **محتويات** هذا المجلد كما هي إلى المستودع `darsfele3ba4-debug/history` (ملف index.html في جذر المستودع).
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة سيعمل الموقع على الرابط: https://darsfele3ba4-debug.github.io/history/
